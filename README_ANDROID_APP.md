# المحلل المالي الاحترافي — Android APK

نسخة Android مستقلة من منصة التحليل المالي، تعمل محليًا دون رفع البيانات إلى خادم.

## الوظائف الرئيسية

- استيراد CSV وExcel مع تعيين ذكي للأعمدة.
- القوائم المالية والتحليل الأفقي والرأسي.
- 42 نسبة ومؤشرًا ماليًا مصنفة حسب السيولة والربحية والكفاءة والمديونية والتدفقات والنمو والموازنة.
- مقارنة الفترات والفروع ومراكز التكلفة والعملاء.
- الموازنة مقابل الفعلي، التوقعات، السيناريوهات، مؤشر الصحة المالية، المخاطر والتنبيهات.
- تقارير تنفيذية وطباعة PDF وتصدير CSV وJSON ونسخ احتياطية.
- واجهة عربية RTL متجاوبة للهواتف والأجهزة اللوحية.

يُعاد تكوين مشروع Android أثناء GitHub Actions من أجزاء المصدر المضغوط، ثم يُبنى APK قابل للتثبيت كأثر Workflow باسم `Financial-Analyzer-Pro-APK`.
