# المحلل المالي الذكي — تطبيق Android

هذه نسخة Android احترافية مستقلة عن نسخة GitHub Pages الحالية، حتى يبقى الموقع المنشور مستقرًا أثناء تطوير التطبيق.

## ما يتضمنه الإصدار التجريبي 2.0

- واجهة عربية RTL مخصصة للهاتف والتابلت وسطح المكتب.
- استيراد ملفات XLSX وXLS وCSV ودمج عدة ملفات.
- التعرف التلقائي على أسماء الأعمدة العربية والإنجليزية.
- تخزين البيانات محليًا في IndexedDB مع بديل LocalStorage.
- لوحة قيادة تنفيذية ودرجة مركبة للصحة المالية.
- تحليل الإيرادات والمصروفات والربح والموازنة والنقدية.
- تحليل أفقي ورأسي للقوائم المالية.
- 18 نسبة مالية موزعة على السيولة والربحية والمديونية والكفاءة والنمو.
- فحص جودة البيانات، التكرارات، القوائم الناقصة، العملات، وتوازن المركز المالي.
- مقارنات حسب الفترة والفرع ومركز التكلفة والعميل والفئة.
- محرك تفسيرات وتوصيات مبني على قواعد مالية واضحة.
- تصدير JSON وCSV وملخص نصي والطباعة إلى PDF.
- بناء APK تلقائيًا من GitHub Actions.

## تشغيل نسخة الويب محليًا

```bash
cd mobile
npm install
npm run dev
```

## إنشاء Android محليًا

```bash
cd mobile
npm install
npm run build
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

يوجد ملف APK الناتج عادة في:

```text
mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

## بناء APK من GitHub

Workflow باسم **Build Android APK** يعمل تلقائيًا على فرع التطوير وطلبات السحب. بعد نجاحه، يظهر ملف `financial-analysis-android-apk` ضمن Artifacts في صفحة التشغيل.

## ملاحظات الإصدار

هذا الإصدار Debug مخصص للاختبار. إصدار المتجر يحتاج مفتاح توقيع خاص، اسم نهائي، أيقونات نهائية، سياسة خصوصية، واختبارات على ملفات مالية حقيقية وكبيرة.
